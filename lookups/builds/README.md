# Generated lookup submissions

Successful builds write `<pet>/<version>.compact.html` and a matching
`<pet>/<version>.counts.json`. Commit both alongside the readable source for
review. Do not edit them manually. Build output is not published automatically.

Paste the complete contents of the compact HTML file only after Tori approves
submission. Do not paste the JSON report or add extra code without recounting.

A failed build does not refresh existing output. Do not use an old output after
a failure. `--check` verifies that both artifacts match the current source.

There is no Amita build until the confirmed source is supplied and imported.
